# 우가 디자인시스템

기준일: 2026-09-17. 첫 번째 참고 이미지의 밝은 브랜드 보드 구성과 일곱 가지 색상을 유지하고, 두 번째 이미지의 수염 있는 우가 캐릭터와 확정한 Primary Logo Lockup을 기준으로 완성했다.

## 살아있는 컴포넌트 명세

현재 UI 동작·상태·props의 기준은 실제 앱 컴포넌트를 연결한 **Storybook**이다. `npm run storybook`으로 실행하며, [UI 컴포넌트 체계](./ui-component-system.md)에서 계층·적용 현황·검증 규칙을 확인한다. 아래 정적 보드는 브랜드 방향과 시각 참고 자료로 유지한다.

## 보드와 원본

- [브랜드 보드](../design/uga/system/brand-board.png): 기본 로고, 앱 아이콘, 아바타, 단색 아이콘, 팔레트, 주요 카피, 키워드, 카드 헤더, PICK 배지, FAB, 빈 상태, 스티커, 컴포넌트 사용 예시.
- [UI 규칙 보드](../design/uga/system/ui-board.png): 글자·금액 위계, 버튼 상태, 입력·선택, 열린 선택창·달력, 오류·파일 선택, 표면·간격, 기능 아이콘, 표정, 상황별 캐릭터.
- [반응형 HTML 보드](../design/uga/system/index.html). 앱 정적 경로 `/brand/design-system.html`에서도 동일한 보드를 제공한다.
- [테마 계약](../design/uga/system/theme-contract.md): 색상 의미, 대비, 크기, 초점, 모션, 사용 원칙.
- [SVG 에셋 목록](../public/brand/manifest.json): 38종의 파일·출처·제작 방식.

브랜드 원형은 [대표 캐릭터](../design/uga/representative/uga-character-v1.png)와 [Primary Logo Lockup](../design/uga/primary-logo/uga-primary-logo.svg)이다. 앱용 SVG는 `public/brand/`에 둔다. Primary 로고는 승인된 SVG와 바이트가 동일하다. 나머지 캐릭터는 같은 참고 이미지의 얼굴·수염·머리·점박이 옷·뼈다귀를 유지해 벡터화하거나 조합했다. UI 아이콘은 브라운 윤곽과 뼈·돌·가죽·종이 모티브로 구성했다. 명암과 질감은 벡터 면으로 단순화했다.

38종은 캐릭터 1, 로고·워드마크 3, 앱 아이콘·단색·머리 3, 아바타 4, 스티커 9, 기능·모티브 아이콘 15, 배지·카드 헤더·빈 상태 3종이다. SVG 안에는 래스터 이미지, 실행 스크립트, 외부 글꼴이나 외부 연결이 없다. 한글 로고·배지 글자도 경로다.

## 앱의 공통 기준

[tokens.css](../src/client/brand/tokens.css)가 보드와 앱의 공통 원본이다. 보드 생성기는 이 파일을 읽어 HTML에 포함하고, 앱과 Storybook은 `app-styles.css`에서 다른 CSS보다 먼저 불러온다. 토큰을 변경하면 보드도 다시 생성한다.

| 역할          | 기준                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------ |
| 브랜드 팔레트 | 브라운 `#5B4636`, 코랄 `#F08A5D`, 샌드 `#F6E1C7`, 민트 `#A7D7C5`, 스카이 `#7CC7F2`, 크림 `#FAF8F4`, 차콜 `#4B4B4B` |
| 행동·선택     | 주요 행동은 브라운, 선택·링크는 대비를 높인 코랄 `#AD4F2C`                                                         |
| 의미 색       | 수입·성공, 지출·오류, 주의, 안내를 각각 라벨과 색으로 구별                                                         |
| 글자          | 한국어 OS 글꼴, 본문 15px, 제목 30px, 주요 금액 최대 36px, 숫자 고정 폭                                            |
| 형태          | 카드 22px, 컨트롤 14px, 다이얼로그 28px, 따뜻한 표면과 얕은 그림자                                                 |
| 조작          | 주요 조작 44px, 입력 48px, 불투명 3px 키보드 초점                                                                  |
| 모션          | 120–220ms 속성별 전환, 동작 줄이기 설정 지원                                                                       |

기존 `--blue` 같은 변수는 호환용 이름이며 실제 값은 의미에 맞는 `--brand-*` 토큰으로 연결한다. 사용자·태그·카드·통장·가계부에 저장된 색상은 브랜드 팔레트로 덮어쓰지 않는다. 차트의 기본 색상만 브랜드 팔레트를 사용한다.

[Uga.tsx](../src/client/brand/Uga.tsx)는 로고·캐릭터·아바타·기능 아이콘·일러스트를 공통으로 제공한다. 이미지의 크기를 예약하고, 장식은 빈 대체 텍스트로 처리한다. 탐색 버튼에는 기존 기능 이름을 유지한다. 가계부의 기존 emoji 저장값은 표시할 때만 브랜드 SVG로 대응한다.

## 화면 적용

| 위치           | 적용                                                                  |
| -------------- | --------------------------------------------------------------------- |
| 로그인·로딩    | Primary 로고, 가로 로고, 대표 캐릭터, 계정 아바타                     |
| PC·모바일 탐색 | 가로 로고, 기능별 아이콘, 목적 가계부 아이콘, 선택 상태               |
| 가계부         | 제목 아이콘, 금액·거래 목록, 우측 캐릭터 안내, 빈 기록·검색 결과 구별 |
| 자산·카드·통장 | 기능 그래픽, 요약·목록·편집창·기존 카드 색상과의 조합                 |
| 통계·계획      | 의미 색, 차트 기본 팔레트, 계획 그래픽, 필터·선택                     |
| 태그·데이터    | 설정·업로드·검토·이력 아이콘, 빈 상태, 파일·선택·입력                 |
| 공통 조작      | 버튼, 팝업, 달력, 태그, 색상 선택, 툴팁, 오류, 다이얼로그             |

캐릭터는 브랜드·안내·프로필·빈 상태에 배치한다. 거래마다 장식 그림을 반복하지 않으며, 화면의 금액과 기록을 먼저 읽을 수 있게 한다. 검색·닫기·화살표 등 일반 조작 기호는 기존의 명확한 형태를 유지한다.

## 재생성과 검증

보드 생성은 Python 표준 라이브러리만 사용한다. 보드 렌더링은 프로젝트의 Playwright와 Chromium을 사용한다.

```sh
python3 design/uga/system/source/build-board.py
node design/uga/system/source/render-board.mjs
npm run check
npm run test:e2e
```

에셋은 `design/uga/system/source/build-assets.py`와 `render-assets.mjs`로 재현한다. 에셋 제작용 Python 도구는 Pillow, NumPy, vtracer 0.6.12이며 앱 의존성에는 추가하지 않았다. 원본 참고 자료와 기능 아이콘 원형은 같은 source 폴더에 보관했다. 승인된 로고는 `design/uga/primary-logo/`에서 가져온다.

브랜드 보드의 금액과 브라우저 테스트 자료는 합성 예시다. E2E는 별도의 임시 DB를 사용한다. 기존 가계부와 Excel, 서버·공유 계산·스키마·저장·인증 계약은 이번 표시 변경의 대상이 아니다. 운영 배포 결과는 이 문서의 로컬 검증과 별개다.

### 최종 검증 결과

- `npm run check`: TypeScript, 단위/API 156개, 프로덕션 빌드 통과. 개인 원본 파일이 필요한 선택 테스트 1개는 제외.
- `npm run test:e2e`: 전체 24개 통과. 등록·수정·자동 저장·충돌·응답 유실·두 사용자 공유·자산 이동·카드 예상액·계획·통계·이관·복원 흐름을 확인했다.
- 모바일 로그인에서 중복 로고와 긴 소개가 첫 버튼을 밀어내는 문제를 수정했다. 이후 `npm run test:e2e -- tests/e2e/design.spec.ts` 3개를 재실행해 PC·320·390px의 7개 화면과 편집창, 첫 로그인 버튼의 완전 노출, 메뉴 초점 복귀, 파일 선택·입력 보존을 확인했다. 이 실행은 수정된 CSS를 다시 빌드했다.
- 디자인 테스트의 이미지 decode 검사에서 모든 앱 브랜드 SVG가 로드됐고 브라우저 예외가 없었다. PC와 모바일 스크린샷, 열린 달력·태그·툴팁을 직접 검토했다. 결과는 `output/playwright/design-*.png`, `controls-*.png`에 있으며 합성 데이터다.
- [보드 렌더 검증](../design/uga/system/board-validation.json): 이미지 54개, 누락 0개, 브라우저 예외 0개, 390px 페이지 가로 넘침 없음. 두 데스크톱 보드도 직접 검토했다.
- SVG 38종 XML 검사: 래스터·live text·스크립트·외부 참조 0개. Primary Logo Lockup은 확정본과 바이트 동일. 구 시안 없이 에셋을 재생성한 뒤 38개 SHA 변경 0개.
- CSS에서 참조한 브랜드 토큰 누락 0개, `git diff --check` 통과. 서버·공유 계산·스키마·의존성 파일 변경 없음.

위 테스트는 현재 소스와 격리된 로컬 환경의 결과다. 이후 사용자 요청으로 Cloudflare 운영 version `7036cc3b-5cf6-4332-9975-1b23b5a7f833`에 배포했다. 운영 정적 파일 44개의 해시 일치, PC·모바일 로그인 화면, 공개 접근 차단을 별도로 확인했으며 [운영 배포 기록](./auth-deployment.md#우가-ui-운영-배포-기록--2026-09-17)에 근거를 남겼다.
