E2E는 별도 임시 DB와 Worker 8790에서 실행한다. 로컬 PoC는 Vite 5173 + Worker 8787이며 migration 0001~0011을 적용했다. XLSX 해석 코드는 데이터 관리 화면을 열 때 분리 로딩한다.

[UI/UX 개선 기준](./ui-ux-design.md)에 공식 조사 출처와 화면별 변경을 정리했다. 월 요약·거래 목록, 자산/카드 핵심 금액, 통계·데이터 목적별 탭, 모바일 하단 탐색·편집 시트를 적용했다. 선택창·날짜/월 달력·태그 뱃지·색상 입력·파일 업로드·툴팁은 자체 공통 컴포넌트로 통일했으며 체크박스·접기·오류 상태도 공통 스타일을 사용한다. UI 개편은 금융 API 연동이나 원격 배포를 포함하지 않는다.

## 4. 운영 전 남은 사항

1. [운영 로그인 설정](./auth-deployment.md)에 따라 Cloudflare 계정 이메일 인증 후 Worker를 배포하고, Google OAuth 클라이언트와 허용할 두 이메일, 최종 HTTPS 주소를 설정한다. 운영 D1은 생성했고 migration 11개만 반영했다. 비밀값을 Git이나 채팅에 넣지 않는다.
2. 배포 후 실제 두 계정으로 로그인·실시간 편집·재접속·만료·로그아웃을 확인한다. 원격 사용량/성능/장기 미사용은 아직 실측하지 않았다.
3. 실자료 반영 전에 결제수단·자산의 실제 대응을 확인한다. 날짜/분류가 불완전한 46행, 유효하지만 자산 연결이 없는 저축 16행, 예비금·가족행사 메모 등은 자동으로 확정하지 않는다.
4. JSON 백업을 개인 저장 공간에 보관하고 복원 절차를 운영 환경에서도 확인한다.

금융 API는 선택 기능이며 제공자를 연결하지 않았다. 태그 조건 자동 배분, 일괄 붙여넣기/수정, 월 마감 잠금, 저장된 분석 조건은 기존 정의서의 후속/추가 검토 범위를 유지한다. 카드 할부·취소·이월·휴일 보정, 금융기관 확정 청구 대사는 현재 자체 예상액 계산에 포함되지 않는다.
