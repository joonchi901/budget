## 1. 상태를 읽는 기준

| 표시 | 의미 |
| --- | --- |
| 설계·구현 중 | 구현할 범위가 정해졌지만 소스·화면·테스트 대조가 끝나지 않음 |
| 소스 구현 | 해당 코드가 존재함. 실행·브라우저 검증 여부는 별도로 확인 |
| 로컬 검증 | 기재한 로컬 명령·시나리오에서 확인됨. 원격 운영 검증은 아님 |
| 후속 필수 | 기능 정의서의 기본 범위에 남아 있으며 아직 완료하지 않음 |
| 선택·추가 검토 | 기존 합의에 따라 별도 채택 여부 또는 상세 범위 결정이 필요한 기능 |

## 4. 검증 기록

2026-09-16, Node.js 24에서 수행한 실행 결과다. 서버 테스트는 로컬 Miniflare의 Worker·D1·SQLite 기반 Durable Object를 사용한다. 브라우저 테스트는 매번 별도 임시 DB를 만드는 [E2E 실행 스크립트](../scripts/e2e.mjs)와 로컬 Chromium을 사용한다. 개발 DB를 바꾸지 않으며, 빌드된 정적 파일과 API를 함께 제공하는 Worker `8790` 포트를 검사한다. 실제 운영 계정·원격 Cloudflare 검증은 포함하지 않는다.

## 5. 명시적인 미검증·미구현 항목

- 실제 사용자 계정 로그인, 금융기관 계정 연결, 실제 사용자 데이터 이관은 수행하지 않았다.
- 원격 Cloudflare 리소스의 실행·국내 반영 지연·장기 미사용·무료 사용량을 측정하지 않았다.
- 세션 만료 시 HTTP 접근과 변경 알림 전달 차단은 검증했다. 알림 없이 만료된 WebSocket의 전송 계층 종료 이벤트가 즉시 완료되는지는 Miniflare에서 지연이 관측되어 미검증이며, 명시적 로그아웃의 연결 종료는 확인했다.
- 미저장 입력의 탭 닫기·새로고침 경고는 구현했지만, 브라우저를 종료한 뒤 초안을 복원하는 기능과 완전한 오프라인 편집은 구현하지 않았다.
- 가구당 협업방 하나를 사용하는 첫 구현 선택과 시스템 기준서 v1.1의 가계부별 방·공유 방 구성은 추후 문서 동기화가 필요하다.
- 카드 예상 청구는 금융기관이 확정한 청구액이 아니다. 현재 마감일·납부일의 월말 보정은 구현했고, 할부·취소·이월·은행 휴일 보정은 미지원이다.
- 자산 평가 기준일·과거 재적용·월별 스냅샷·완전한 변경 이력 UI는 구현 여부를 별도로 확인해야 한다.
- 여러 행 붙여넣기·일괄 수정·전월 복사·월 정리 완료 및 잠금·저장된 분석·다중 부모 연결은 기본 구현 완료 조건으로 승격하지 않는다.
- 개발용 초기화나 가상 데이터 주입은 사용자 백업·복원 기능의 구현 증거가 아니다.
