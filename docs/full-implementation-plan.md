기준: 2026-09-16 원본 Excel 28개 시트 감사 및 기능 정의서 FAC-01~22.
사용자 요청: 감사에서 확인한 기능 전체를 구현한다. 아래 항목이 모두 실제 구현과 검증으로 입증되기 전에는 전체 완료로 표시하지 않는다.

## 유지하는 규칙

- 의료비 전용 정산 제외. 금융 API 연동은 제공자 미선정 선택 기능이다.
- 가계부 거래는 수입/지출, 저축은 자산 변동에서 집계, 이동/평가는 자산에서 관리한다.
- 예비금은 일반 자산이다. 여행 가계부와 자동 연결하지 않는다.
- 예산·급여 배분·행사 계획만으로 거래나 자산 변동을 만들지 않는다.
- 카드 구매는 한 번만 소비 지출, 청구 예상액은 별도 정보다.
- 하위 거래 원본은 복사하지 않는다. 메인 연결/해제는 자산 효과를 재생성하지 않는다.
- 수정 충돌, 재전송 중복 방지, 과거 참조 보존을 새 설정에도 적용한다.
- 원본의 누락 분류·단위·불완전 날짜·음수 숨김을 보고하고 임의 보정하지 않는다.
- 원본 개인 금융자료와 그 추출본을 Git에 추가하지 않는다. 테스트 fixture는 비식별 합성 자료로 만든다.

## 완료 기준과 증거 범위

다음은 수용 기준이다. 개별 기능과 연결 흐름은 합성 자료·로컬 브라우저로 검증했으며, 빈 운영 DB의 초기화는 API 테스트로 확인했다. 실제 두 계정으로 빈 운영 환경에서 전체 과정을 수행하는 검증은 배포 후 진행한다.

1. 빈 데이터에서 사용자 설정만으로 등록→계획→입력→월말 조회까지 가능하다.
2. 원본 유지 대상의 거래·관리·계획 데이터를 이관하고 제외·오류·중복 결과가 설명된다.
3. 월/연/항목별 수치가 독립적으로 산출한 기대 결과와 맞거나 승인된 규칙 변경의 차이가 설명된다.
4. 날짜 경계, 과거 잔액, 복수 태그, 하위 연결, 카드 청구, 재시도에서 중복 금액이 없다.
5. 백업 후 복원한 데이터·관계·계획·저축 값이 동일하다. 세션/인증정보는 백업에 없다.
6. 실제 두 사용자 인증과 공동 편집, PC/모바일 조작을 각각 검증한다.

원격 인증/배포와 원본 실자료 이관은 소스·합성 테스트·로컬 화면과 구분해서 증거를 기록한다.

최신 증거: [구현 현황](./implementation-status.md), [원본 검증 보고서](./excel-parity-audit.md). 실제 운영 계정·배포·원본의 미확정 연결은 사용자 환경에서 확인해야 하며 로컬 구현 완료와 구분한다.

로컬 구현 커밋: `465b6b1`. 타입 검사·단위/API 156개·브라우저 16개·빌드를 통과했다. 실제 원본은 별도의 선택 테스트와 독립 계산으로 대조했으며 개인 자료는 커밋하지 않았다.
