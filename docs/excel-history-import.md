# 엑셀 이력 가져오기

## 기록과 결제수단

수입·지출의 결제수단은 선택 항목이다. `transactions.payment_method_id`와 API의 `paymentMethodId`에 `null`을 저장하며, 화면에서는 **미지정**으로 표시한다. 임의의 현금·카드·통장 항목을 만들지 않는다.

- 결제수단 없이 거래를 저장·편집하고 목록·캘린더·통계에서 조회할 수 있다.
- 미지정 거래도 수입·지출 합계에 포함한다. 카드 예상 대금은 해당 카드에 연결된 거래만 집계한다.
- 나중에 결제수단을 지정하거나 해제할 수 있다. 자산 반영은 거래의 자산 배분에 따라 별도로 처리한다.
- CSV에서는 빈 결제수단을 `null`로 왕복한다. 이름이 있는데 연결 대상을 찾지 못한 경우에는 오류를 표시한다.
- `0013_nullable_transaction_payment.sql`은 기존 거래 및 참조 자식 기록을 보존하며 결제수단의 NOT NULL 제약만 완화한다.

## 태그와 가계부 배치

엑셀 설정과 월별 원장에 있는 분류·내역 분류·추가 태그를 등록한다. 예비금 관리표의 항목도 별도의 자산용 태그 유형으로 등록한다. 아직 거래로 반영하지 못한 행의 태그도 보존한다. 원문에 없는 분류를 추정해서 만들지 않는다.

새 가계부를 만들 때 두 구성을 선택할 수 있다.

- 하나의 가계부: 모든 거래·계획을 같은 가계부에 저장한다.
- 월별 하위 가계부: 상위 가계부와 1~12월 하위 가계부를 만들고 원본 월 시트에 따라 거래를 배치한다. 월 시트의 계획은 해당 하위 가계부, 공통 계획은 상위 가계부에 저장한다.

같은 원본을 다시 가져올 때는 처음 선택한 구성을 유지한다. 이미 반영한 거래를 재가져오기로 자동 이동하거나 덮어쓰지 않는다. 가져오기 완료 화면의 **가져온 가계부 보기**는 하위 가계부와 전체 기간의 목록을 연다.

새 가계부의 조회 기간은 원본 월별 시트에 적힌 시작일·종료일, 월 헤더, 설정의 회계 연월 순서로 확인한다. 판단할 수 없는 기간은 검토 항목으로 남긴다. 기간이 설정된 목적 가계부를 열면 설정 기간으로 조회하며, 선택 중인 달이 범위 밖이면 시작 월로 이동한다. 기존 가계부의 기간을 재가져오기로 덮어쓰지는 않는다.

## 미확정 자료

날짜·양수 원 단위 금액·내역·수입/지출 구분이 확인된 행을 거래로 반영한다. 내역 분류만 없으면 실제 존재하는 태그로 거래를 저장하고 분류 확인 항목을 남긴다.

다음은 원문을 검토함에 남기고 의미를 임의로 확정하지 않는다.

- 날짜 또는 수입/지출 구분이 불명확한 행
- 음수 금액의 환불·취소·정정 여부
- 저축의 출금·입금 자산과 기존 월말 관측 잔액에 포함됐는지 여부
- 예비금 유입의 성격과 월별 지출에 이미 기록된 사용 내역
- 잔액 기준일이 없는 자산 및 여러 관리표의 동일 자산 여부
- 금액 없이 입력한 내역·메모

검토함에서 메모·상태를 변경하는 동작은 거래·자산을 자동 생성하지 않는다. 실제 거래 반영과 검토 완료는 별개의 상태다. 의료비 전용 정산 기능은 기존 제외 범위를 유지한다.

## 원본 보관

가져오기 후보에 원본 XLSX 바이트를 작은 조각으로 함께 보관한다. `source_records`의 참고 자료이며 수입·지출 합계에는 포함되지 않는다.

- SHA-256을 검사해 원본 파일을 정확히 복원한다. 누락·중복·손상된 조각은 다운로드·읽기를 차단한다.
- 데이터 관리의 **엑셀 원본**에서 시트·셀 주소·값·수식을 검색할 수 있다. 숨긴 시트도 조회할 수 있다.
- 주석·도형·차트·서식은 원본 다운로드로 보존한다. 웹의 셀 조회는 엑셀 레이아웃을 재현하는 기능이 아니다.
- 수식·매크로·외부 링크를 실행하지 않는다. 셀 값은 파일에 저장된 결과를 읽는다.
- 금융 원본과 운영 DB 백업은 Git에 추가하지 않는다.

## 저장과 검증

현재 자료를 포함한 후보를 만들고 서버가 형식·참조·기간·권한을 검증한다. 관리자 권한과 미리보기 이후 변경 여부를 다시 확인한 뒤 한 번의 DB 배치로 반영한다. 원본 식별자와 행 위치를 유지한 재가져오기는 중복 행을 만들지 않는다.

백업은 네 테이블씩 묶어 개별 행을 읽는다. 복원과 변경 이력은 JSON 바인딩을 UTF-8 150만 바이트 이하로 나누면서 하나의 원자적 배치에 유지한다. 이는 [D1의 문자열·쿼리 제한](https://developers.cloudflare.com/d1/platform/limits/) 안에서 원본 파일을 포함한 자료를 처리하기 위한 구성이다.

검증은 결제수단 null의 저장/편집/백업 왕복, 마이그레이션의 기록·FK 보존과 실패 롤백, 태그 및 월별 배치, 원본 바이트 복원, 실제 원본을 사용하는 비공개 임시 DB 대조를 포함한다. 소스 검증이나 임시 DB 통과와 운영 반영 결과는 별도로 확인한다.

### 이전 기록을 보는 방법

1. 왼쪽 가계부에서 **2026**을 선택한다.
2. **가계부 설정 기간 · 하위 가계부 포함**으로 전체 거래를 조회한다. 월별로 보려면 해당 월 하위 가계부를 선택한다. 기간이 지정된 가계부는 해당 기간으로 열리고, 캘린더의 조회 월도 범위 안으로 맞춰진다.
3. **데이터 관리 → 엑셀 원본**에서 전체 원본을 조회하거나 내려받는다.
4. **데이터 관리 → 원본 검토함**에서 보류 사유와 원문을 확인한다. 미확정 기록은 원장 합계와 구분된다.
