# 우가 스티커와 장식

감정 스티커 18종, 대화 스티커 12종, 장식 23종을 개별 투명 PNG로 제공한다. 스티커에는 문구를 넣지 않아 같은 표정에 상황에 맞는 말을 붙일 수 있다.

| 세트             | 파일 캔버스 | 미리보기 표시 크기 |
| ---------------- | ----------- | ------------------ |
| 감정·대화 스티커 | 256 × 256px | 92px               |
| 장식             | 128 × 128px | 24px               |

256px와 128px는 각각 [기존 스티커와 장식의 SVG 크기](../../../public/brand/manifest.json) 범위 안에서 선택했다. 종횡비를 유지하고 투명 여백으로 정사각 캔버스를 맞췄다.

- [에셋 목록](../../../public/brand/reactions/manifest.json)에서 이름, 분류, 파일 경로, 크기를 확인할 수 있다.
- 내역 반응에는 스티커 30종을 96px로 줄인 사본(`public/brand/reactions/stickers-96/`, 장당 약 15KB)을 칩 22px·고르기 44px로 쓴다. 이름 목록은 `src/client/brand/icon-names.ts`의 `UGA_REACTIONS`이고, 서버도 이 목록으로 저장할 반응을 검사한다.
- [스티커 미리보기](./sticker-preview.png)는 92px 크기로 그렸다.
- [장식 미리보기](./decoration-preview.png)는 왼쪽에 확대 이미지, 오른쪽에 24px 이미지를 그렸다.
- [생성 프롬프트](./prompts.json)에는 각 그림에 사용한 장면 지시와 공통 스타일 지시가 있다. 기본 ImageGen으로 각 그림을 따로 생성했다.
