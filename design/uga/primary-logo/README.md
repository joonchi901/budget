# 우가 Primary Logo Lockup

사용자가 제공한 `ChatGPT Image 2026년 9월 17일 오전 08_40_05.png`의 **왼쪽 대형 로고**를 기준으로 만든 단일 벡터 자산이다. 원본의 윙크·들어 올린 뼈다귀·점박이 옷·돌 글자·아래 명패 구성을 유지한다.

- `uga-primary-logo.svg`: 투명 배경, 480 × 667 viewBox (사방 12px 여백), 독립 SVG 경로. 래스터 삽입·외부 글꼴·외부 링크 없음.
- `uga-primary-logo.png`: 같은 SVG를 렌더링한 투명 PNG.
- `uga-primary-logo-preview.png`: 확인용 크림 배경 미리보기.

원본 윤곽을 색상 면과 곡선으로 벡터화했다. 작은 명패의 ‘우리의 가계부’는 확대 시 거친 윤곽이 보이지 않도록 둥근 벡터 획으로 정리했다. 원본의 미세한 질감과 명암은 벡터 면으로 단순화했다. 확정된 파일은 [현재 디자인시스템](../../../docs/uga-design-system.md)과 앱에 동일하게 사용한다.

`source/logo-reference.png`는 원본의 (24, 118)–(480, 761) 영역에서 배경·인접 스티커를 제외한 제작용 참고 이미지다. 이 PNG는 완성 SVG에 포함되지 않는다. `source/build-logo.py`와 `source/subtitle.svg`로 재현할 수 있다. 변환 도구는 임시 환경의 vtracer 0.6.12를 사용했으며 앱 의존성·화면은 변경하지 않았다.
